Программа: Трекер подписок и регулярных расходов.
Автор проекта: ученик 9 класса

Инструкция по использованию приложения:
1. Кнопка "Добавить" - открывает форму для создания новой подписки.
2. Кнопка "Изменить" - позволяет отредактировать данные выбранной подписки.
3. Кнопка "Удалить" - навсегда стирает запись из базы данных с подтверждением.
4. Кнопка "Оплатить" - вручную переносит дату списания на следующий период.
7. Кнопка "Сбросить фильтры" - полностью сбрасывает поиск, фильтр календаря и сортировку колонок.
5. Строка поиска - фильтрует подписки по названию прямо во время ввода.
6. Интерактивный календарь - показывает подписки, запланированные на конкретный выбранный день.
7. Горячая клавиши 'ctrl + n' может открывать окно добавления прямо с клавиатуры, не нажимая на кнопку.
8. Экспорт в Excel (CSV) - выгружает весь список подписок из базы данных в полноценный табличный файл report.csv.
9. Очистить всю базу - системная функция для полного удаления всех  данных из таблицы подписок.

* Система автоматически проверяет дату с ПК при каждом запуске и переносит просроченные подписки вперед с учетом их периодичности
